## 建议数据结构

正式迁移应把原型的简化 claim 拆为可版本管理的实体与关系：

```ts
type CulturalObject = { id: string; name: string; scopeNote: string }
type Practice = { id: string; objectId: string; name: string; featureIds: string[] }
type Interpretation = { id: string; text: string; scope: string; provenanceIds: string[] }
type Source = {
  id: string; title: string; publisher: string; canonicalUrl: string;
  sourceType: string; accessedAt: string; versionHash?: string; rightsNote: string
}
type SourceSpan = {
  id: string; sourceId: string; locator: string; text: string;
  page?: number; chunkId?: string; start?: number; end?: number
}
type Relation = {
  id: string; from: string; to: string; kind: string; scope: string;
  spanIds: string[]; origin: 'curated' | 'model';
  sourceLocated: boolean;
  semanticState: 'not_reviewed' | 'model_supported' | 'human_reviewed' | 'insufficient';
  interpretationNote?: string; review?: { reviewer: string; at: string; decision: string }
}
```

共同点由同维度、同范围、经审读的feature交集生成；不可只按名称、坐标或共现合并。缺失资料记录为 unknown，不能默认 false。地方解释差异独立于支持状态，避免把多元叙述当二元矛盾。来源位置校验、语义审核和审核者记录是独立字段；审读记录应带版本和意见，不能用一个绿色 supported 覆盖全部。

网页本轮用条目与段落定位，不伪造 PDF page/chunk。后续只有真实导入并冻结版本后才生成哈希、片段范围和页码。引句修改必须保留前一版本及审计事件。

## 中文检索与D6风险处理

D6中纯中文A08没有词面种子，而显式英文术语探针改善候选位置召回。它是小样本跨语言瓶颈，不证明对本轮中文文化语料的具体失败率。正式迁移先建独立人工审读的小型中文诊断集，覆盖地方别称、仪式同义词、否定、时间和无答案问题；保留原BM25作为对照。优先试验规范化、分词与人工别名（如竞渡/赛龙舟），对照同预算 Recall 与排序；别名扩展记录原词、扩展词及来源，避免把词汇近似误当文化等同。只有实测仍不足，另行评估混合语义检索的收益、成本和数据许可，不在本轮引入Embedding/RAG框架。

D6固定夹具出现真引句但结论方向、否定、条件或单位错误仍被支持，以及合理意译被拒的情况。它们证明现有保护边界，**不是总体错误率**。迁移时来源校验先于关系发表；AI只提出 provisional 候选，关系方向、否定、人物范围、时期与单位分别检查；关键文化关系必须独立人类审读。语义模型复核仍只是模型判断，不升级为事实认证。不能用“官方网页”“模型支持”或三维实线造成确定性错觉。

D6补检三组规划不同，不能根据支持数差声称因果提升。未来只有冻结规划/初始证据或明确标记非严格配对后，才评估新增去重证据与需求覆盖。原型没有接入补检，也没有把静态摘编展示成检索轨迹。

## 版权、素材及文化表达

页面公开不等于图像自由使用。本轮不下载网页照片、影像和音乐，不嵌第三方字体；舟形SVG与三维几何为原创示意。只保留有限短摘录、原创转述、出处和定位，不提交整篇复制件。正式展览前应确认网站内容使用条款、图片/影像许可、字体授权、人物肖像和地方仪式展示的适宜性；必要时邀请传承人与地方研究者共同审读，避免把活态文化压缩为地域刻板印象。

## 最小正式开发与后续阶段

以下是建议的 **C系列实施顺序**，区别于原D7；每阶段需用户明确启动，一次提交验收后停止。

| 阶段 | 最小范围 | 验收条件 |
| --- | --- | --- |
| C1 内容与状态基线 | 三个地方、当前9条关系及少量必要上下文；冻结来源版本、字段与权限 | 每条关系有真实出处、范围、版权备注；独立审读人与意见可追溯；未知联系不进入已核对集 |
| C2 可用性与浏览工作流 | 按原型迁移探索、对照、剖面及观察草稿；先采用审核数据，不接生成 | 约5名目标学生能完成端到端任务并指出依据/空白；三种尺寸无阻断；WebGL故障与键盘列表实测 |
| C3 中文检索与候选发现 | 人工别名/分词实验；受控模型候选，预算与轨迹 | 预注册诊断集与同预算对照；所有AI结果provisional；无答案/否定陷阱可记录失败，不用改样例刷分 |
| C4 展览与可靠性 | 来源更新提示、审核回滚、档案持久化和合规素材；测量再优化 | 历史回放不漂移、素材许可完整、目标设备性能记录与离线展示方案 |

第一步建议先做 C1，而不是立刻接模型或继续增加视觉特效。本轮不实施任何正式迁移。
