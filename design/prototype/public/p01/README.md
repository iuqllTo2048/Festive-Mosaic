# P01 首页素材

原文件来自用户 `photoResource/FestiveMosaic_P01_Codex_Package`。9张PNG保持原字节，SHA256与大小见 `manifest.json`。

- `art/01_*`：默认融合画卷。
- `art/02_*`至`06_*`：春节、清明、端午、七夕、中秋完整展开图。
- `ui_assets/07_*`：花饰提示。
- `ui_assets/08_*`：导航。
- `ui_assets/09_*`：节日下拉框。

导航和下拉框以这些图片为视觉基底，并覆盖原生交互控件。源包、ZIP、参考提示词不随静态资源发布；本目录全部为当前首页实际使用资产。
