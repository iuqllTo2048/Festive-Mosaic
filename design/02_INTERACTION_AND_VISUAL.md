# 02｜交互与视觉规范

## 信息架构与页面

一级导航为文化探索、异俗对照镜、观察档案。内容与使用说明常驻，资料剖面是保留上下文的原生模态抽屉。所有页面明确标记静态 DEMO。

**A 首页**：桌面上部为左侧主题标题与右侧原创舟形剖面；下部是三行编号问题，具有完整句子、探索方向和进入箭头。留白与细分隔线建立阅读顺序，不使用一排功能卡片或大输入框。图形的三条剖面分别标记实践、解释和依据；说明其为抽象图形，非实物复原。

**B 层理工作台**：顶部显示正在阅读的问题；左侧地方目录，中部维度切换与关系空间，右侧观察提示与状态解释。1440 布局为约208 / 自适应 / 250像素三栏，边距48。图谱高352像素，来源阅读进入右侧570像素抽屉。1024缩小边距和目录宽度；不足950时观察提示下移。面板允许纵向滚动，不强求所有资料挤入一屏。

**C 对照界面**：两个明确标记 A/B 的文化主题选择器；比较维度常驻；共同记录摘要位于空间之前。空间左右分置地方节点，中央只出现由 feature 交集生成的共享节点；下方两列分别列出本方资料。共同来源入口可切换双方出处。不用模糊的“相似度百分比”代替阅读。

**档案**：左侧保存探索问题、对象与资料范围，右侧保存文化关系、共同点提示和可编辑的待查问题。共同点只由已经保存且跨地方共享 feature 的记录提示；差异保留在每条关系的解释中，不自动编写新结论。当前只是一份浏览器本地草稿，未接账号、云同步和导出。

## 三层模型与三维决策

| 层次 | 节点表现 | 空间意义 | 点击后 |
| --- | --- | --- | --- |
| 实践 | 地方色圆点，简短活动名 | 上层；不同地方占各自栏目 | 打开对应文化说法 |
| 解释 | 青灰菱形，解释名 | 中层；连接该地方实践与出处 | 仍打开该说法，避免把脱离语境的词当事实 |
| 依据 | 旧金矩形，S编号 | 下层；相同来源去重 | 进入带标题、主体、段落定位与链接的资料剖面 |
| 共享实践 | 中央青灰圆点 | 仅双主题同维度真实 feature 交集 | 阅读两方分别的出处与解释 |
| 候选联系 | 空心菱形与点线 | 实践维度保留未证实问题 | 证据不足说明，不生成支持结论 |

布局由主题顺序、维度、记录行数和共享关系确定；没有地理坐标、随机位置和无意义自动旋转。源记录稳定生成节点和边，相机适应当前范围。三维用于并读三层来源链，以及将共享实践置于地方差异之间；它不是唯一的内容入口。若完全移除三维，用户仍能完成阅读，但会失去旋转观察遮挡路径、在一个空间看到层间联系与中央共享节点的体验。这项增量价值尚需用户测试，不宣称3D必然优于列表。

本轮选择确定性 Three.js 布局。原有3d-force-graph保留为后续候选；文化阅读不应预设为不断运动的力导向网络。当前规模每次只显示一个维度。正式数据扩大后先限制每视图约30个可读节点，增加逐层展开、来源聚合及按问题筛选，再实测性能；此数字是待验证设计预算，不是已测容量。

## 状态与操作

| 状态 | 触发与反馈 | 退出/降级 |
| --- | --- | --- |
| Hover | 指针移至三维节点，底部显示节点层次与完整标签；列表整行反馈 | 移走恢复操作说明 |
| Click | 节点或关系线打开同一 claim 的剖面，原空间保留 | 关闭按钮或 Escape；原生 dialog 管理焦点与背景访问 |
| Focus | 点三层筛选按钮，保留形状与文字，其他层降低透明度；选中关系后突出相应路径 | 全览、复位或无弹窗时 Escape |
| Compare | 更换 A/B 与维度，立即依据数据重新组织节点和共同记录 | 返回层理探索；不插入装饰过渡 |
| Reset | 清除选择与层筛选、相机回到适配视角 | 不清空收藏 |
| Source Inspection | 先读实践与解释，再读来源定位；短摘录分别排版，不拼为伪连续引文 | 官方全文新页打开，原型上下文保留 |

实线表示本轮摘编的实践—解释联系，虚线表示资料出处或对照连接，点线表示待查联系；它们不是置信度刻度。节点形状表达类型，状态必须另附文字。完整边类型见 content.mjs，不把术语共现解释为历史关联。

状态语义分别为：来源已定位、模型认为支持、人工已核对、证据不足、解释差异。原型只使用已定位与不足两种记录状态，另外三种在说明中明确是未来或解释性状态，**不生成虚构的模型判断或人工审核徽章**。解释差异不等于逻辑冲突。

## 视觉执行参数

| 项 | 具体规范与理由 |
| --- | --- |
| 底色/文字 | 纸本 #F3F0E8，阅读面 #FAF8F2，炭墨 #2C302B；正文避免纯白与纯黑的强硬对比 |
| 强调 | 赭红 #8E4539用于主题和主要动作；青灰绿 #49675C用于关系与共享元素；旧金 #7B653D用于资料标记；不用色彩表达真假 |
| 辅助 | #686B60辅助正文，#D6D0C3细分隔线。低对比线条只作装饰，不承载唯一信息 |
| 字体 | 标题使用系统宋体类衬线（Songti SC / SimSun / serif），正文 Segoe UI / Microsoft YaHei / sans-serif；没有下载字体。首页桌面58px、移动43px；工作台主标题29px，正文14px，索引8–12px。小号元数据在手机上仍须真机可读性评估 |
| 间距 | 以4px为基本单位，8/12/16/24/32/48/64分级；细线分区替代圆角卡片堆叠；标题与资料引文使用较宽行距 |
| 组件 | 主按钮实色矩形，次按钮细描边；整行问题可点击；资料抽屉固定页头/底部操作，中部独立滚动；原生select保留键盘行为 |
| 图形 | 原创SVG舟形与档案索引线；三维只用简明几何节点。无地图、行政轮廓、粒子、光晕、水墨贴图或未授权照片 |
| 动效 | CSS色彩/边框过渡160ms，仅系统允许动效时启用。Three.js按交互重绘，无空闲动画循环；不以动画速度隐喻文化关系强弱 |

## 手机、无障碍与故障状态

390×844默认使用同源关系列表，目录变横向按钮，A/B选择器可换行，资料抽屉全宽。层理和对照列表保留 claim ID、地方、实践、解释和来源入口；共享记录仍位于列表前。档案改单列。普通页面纵向滚动是设计的一部分。

有跳转主要内容入口、语义标题、select/textarea标签、键盘焦点描边、原生dialog/Escape、状态文字和live提示。三维Canvas不宣称对读屏等价，实际信息通过列表访问。WebGL初始化或上下文丢失会切回同源列表并提示；本轮没有进行GPU故障注入，功能存在不等于故障路径已实测。未完成读屏、色盲模拟、系统缩放200%和真机触控测试。

## 去模板化设计自查

- [x] 首页先呈现文化问题，不以AI输入框或功能三卡片作为主入口。
- [x] 抽象舟形来自本期文化内容，标签解释图形含义，非通用装饰。
- [x] 正文、目录、空间、引文有不同但连贯的阅读层级。
- [x] 对照改变实际关系组织，中央共享元素由记录决定。
- [x] 颜色与线型有信息含义，不用发光表现“智能”。
- [x] 未记录和不同解释都有明确文案，不强造戏剧化对立。
- [ ] 真实学生能否独立说明发现及其依据，仍须用户测试。

实际视口检查与截图索引以 [审查报告](REVIEW_FOR_CHAT.md) 为准；以上规范不等于独立人工视觉验收。
