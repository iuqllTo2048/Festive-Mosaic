2. `backend/tests/test_agent.py`：新增 4 项回归，覆盖同一片段其他位置的术语/数字不能替代引句、正确引句通过、解释可使用同源上下文。`backend/scripts/verify_d3_live.py` 兼容新的审计版本，D3 历史报告不改写。
3. `frontend/src/App.vue`：打开上传浮层时清空原生文件选择值，修复不刷新页面重复选择同一 PDF 不触发 change 的问题。
4. `frontend/src/components/EvidenceGraph.vue`：视角重置不再依赖包含标签及上一帧变换的场景包围盒；按真实节点坐标取景，为文字留空。修复重复重置/缩放窗口时越放越大、图被裁切的问题。
5. `AuditPanel.vue`：旧审计记录明确提示未采用新的引句校验；基础问答不误报为旧审计。
6. `backend/scripts/evaluate_d5.py`、`samples/d5_questions.json`：五题成对执行/缓存复核、来源与计数检查、零匹配基础检索；只有 `--execute` 才提交缺失题目。保存每条原始 request/result，失败不自动重试。
7. `backend/scripts/serve_d5_no_key.py`：以显式空 key 和隔离数据目录提供已构建 UI，仅用于人工无 key/上传验收。README、AGENTS、playbook、评估问题和演示说明同步更新。
