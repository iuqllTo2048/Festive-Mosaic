# 可重复演示指南

正式题目：**VerifiAtlas——面向科研知识探索的智能交互可视化系统**。

## 启动与准备

首次在本地使用时按根目录 README 安装 Python 3.12 / uv / Node 22.12+ 及锁定依赖。两窗口启动：

```powershell
# 窗口 1
Set-Location E:\VerifiAtlas\backend
uv run --locked uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```powershell
# 窗口 2
Set-Location E:\VerifiAtlas\frontend
npm.cmd run dev
```

打开 [工作台](http://127.0.0.1:5173/)。首次运行的机器需在左侧导入官方论文，失败可手动下载后上传；语料数据不随 Git 同步。PDF 上传只发送本机，真正提问才把问题和少量片段发送 DeepSeek。

## 约三分钟的保存记录演示（本机，无新增模型调用）

1. 打开 [D5 能耗缺口记录](http://127.0.0.1:5173/?run=34a31bea-9831-4492-bf93-2e15913e0ebc)。研究问题同时问数据集和焦耳能耗。说明：1/2 项有引用支持，不是可信度 50%。
2. 点击数据集需求，查看相关来源链；点击能耗需求，确认只有需求本身、0 条支持关系。说明：未找到测量不会用时延代替，更不会补造支持边。
3. 点击引用 [1]，在来源抽屉核对 KG2RAG PDF 实际第 5 页、片段 28；原文页序可能不同于印刷页码。点开 PDF 时按显示页码人工确认，不把 `#page` 参数视作已验证阅读器跳页。
4. 关闭来源，聚焦底部滑杆按 Home；规划之前图为空，逐步推进出现真实事件。说明：这是执行结束后的记录回放，动画间隔不是模型耗时。点“回到结果”，本例补检 1 轮，模型请求 3 次，后端耗时 4422ms。
5. 切换“列表”，同一批 22 个节点、42 条关系仍可查来源；切换主题。缩窄窗口可从“语料”“审计与来源”入口继续任务。
6. 可打开 [D5 有限比较记录](http://127.0.0.1:5173/?run=b83747d8-8160-4bf0-a59f-8e59dcb595ae)：只陈述 MuSiQue 局部表格结果，普遍排名仍不足。不要把某张表推广成“所有任务都更优”。

这些 run ID 只在持有本地数据库的机器有效。换机器时先准备语料和后端 key，输入 `samples/d5_questions.json` 的问题重新执行，实际措辞、需求和耗时会变化。

## 现场新提问（会消耗 API）

选择 KG2RAG；展开检索设置，勾选“仅检索当前论文”“拆解需求并审计”“允许一次补检”。从 `samples/d5_questions.json` 复制 E7 的完整问题，点“开始检索”。不承诺每次相同覆盖率；补检后仍缺证据是有效终态。

如果 key 无效、额度不足或网络失败，展示真实错误或部分已核对结果；使用保存记录继续讲解时明确说明是历史执行，不能冒充现场完成。

## 复核与故障展示

```powershell
Set-Location E:\VerifiAtlas\backend
# 已保存数据复核，默认不调用模型
uv run --locked python scripts/evaluate_d5.py

# 可选：隔离的无 key 验收，需先构建 frontend
uv run --locked python scripts/serve_d5_no_key.py
```

无 key 验收打开 `http://127.0.0.1:8001/`；上传文本 PDF 后提问，应明确报未配置 key。数据独立保存在 `backend/data/d5-no-key/`。同 PDF 再次上传应去重；空文件、假 PDF 和空白无文本 PDF 应清晰失败。结束按 Ctrl+C 停止 8001 服务，不需改动正常环境变量。

若 8000/5173 被占用，先检查是否已启动服务，复用已有进程；不要同时启动多个后端 worker。恢复保存记录失败通常意味着当前数据目录没有该 run，使用本机实际生成的 URL。

## 讲解边界与归属

本项目整合本地 PDF 检索、证据需求、一次补检、校验、可追溯图和可访问工作台。图谱术语仅共现；支持判断包含模型判断和有限字符串保护。没有实现完整语义证明、统一跨论文实验、OCR 或其他论文的完整算法。距离和布局仅帮助阅读。

五题真实观察和已知问题见 [D5 验收记录](D5_VERIFICATION.md)。五题的两次需求由模型独立规划，不是因果消融；不宣称统计显著、普遍提升或 SOTA。第三方库及许可证见根目录 `THIRD_PARTY_NOTICES.md`，原论文保持官方署名，PDF 不纳入代码仓库。赛事/学校材料中的 AI 辅助创作与原创性声明应按实际规定如实填写，本项目不作“无 AI 协助”等不实承诺。
